For all animation files (.gif) 6 models are shown. Within the same file, all models receive the same sequence of observations, but they differ in terms of parameterisation. It is noted above each model animation how it differs from standard parameterisation. 
Standard parameterisation is:
- alpha = 0.01
- omega = -6.0
- sigma = 0.0
- lambda = 0.7

See the article for how to interpret the gaussian mixtures. Here the colour of the components reflect the time during the simulation that it was added. The colour gradient in the bottom shows the progression of colours across timesteps. The timestep of each frame is also shown. Note that for long-term animations and trajectory animations only every 10th and 5th update is shown (respectively), to speed up the total animation time. 

Trajectory animations are made to be examples of the trajectory plots in the article. Here the background changes colour to grey during the time span of alternate parameterisation. Here the parameter shown on top of each simulation denote the parameterisation during that time span. When the background is white in the trajectory animations, all models have standard parameterisation. 

The file names indicate the content of the animations. Here DBM denotes "distance between means". DBM6 is unambiguous. DBM3 is ambiguous.
